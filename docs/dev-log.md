- **The data layer (`HW-53`).** Screens will read the household with `useHousehold` and save each action with `useSaveChanges`, both in `src/data/household.ts`. Signing out leaves the copy on the phone for that account, and another account's sign-in throws it away. A warning on Sign out while changes wait is `HW-59` in the backlog, at low priority.
